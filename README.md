# たんたんご！ PWA v10

GitHub Pages上で動く単語学習アプリ。**ホーム → 学習モード → 言語 → CSVセット → 一覧／テスト**の順で選択します。

## 今回の変更

- 学習モード「単語学習」「瞬間作文」の次に**英語・韓国語・中国語**の3択を追加。
- **3列CSV**「原語,拼音,日本語」に対応。中国語の一覧では原語の直下に拼音、右に日本語訳。テストでは原語のみ表示し、タップ後に原語の直下へ拼音、その下に日本語訳を表示。単語位置は固定。
- 5列（旧4列）の英語・韓国語単語テストは、中央寄り・左揃えに変更。例文と訳、5列目強調表示は維持。
- **2・3・4・5列CSVの見出し名は自由**。1行目はヘッダーとして読み飛ばし、2行目以降の実際の列数で判定。CSVの各列の意味・順番は下記に固定。
- CSVは各フォルダへ追加・削除してコミットすれば、GitHub Actionsが自動的にセット一覧を更新。
- 既存の⭐復習情報を保存するIndexedDBはそのまま使用。

## 初期データ

添付の `CSV.zip` から実CSVだけを取り出し、**27セット／2,227項目**を同梱しました。Macで付く`__MACOSX`や`.DS_Store`は除外しました。

| モード | 言語 | セット数 | データ形式 |
|---|---|---:|---|
| 単語学習 | 韓国語 | 8 | 4・5列 |
| 単語学習 | 英語・中国語 | 0 | （初期CSVなし） |
| 瞬間作文 | 英語 | 7 | 2列 |
| 瞬間作文 | 韓国語 | 5 | 2列 |
| 瞬間作文 | 中国語 | 7 | 3列 |

※ 中国語のHSK3級7セットは、**添付ZIPの配置に合わせて `Flash` に収録**しています。そのため「瞬間作文 → 中国語」から選択できます。もし「単語学習 → 中国語」に置きたい場合は `Flash` から `Vocabulary` へCSVを移動するだけで対応できます。

## ディレクトリとCSV形式

```text
リポジトリ直下/
├── index.html
├── app.js
├── styles.css
├── sw.js
├── manifest.webmanifest
├── icons/
├── VocabularySets/
│   ├── Vocabulary/       ← 単語学習。4・5列CSV、または移動した3列中国語CSV
│   ├── Flash/            ← 瞬間作文。2列CSV、現在の3列中国語CSV
│   └── index.json        ← 参考用の初期カタログ。公開時に再生成
├── scripts/
│   └── build_site.py     ← CSVチェック・言語判定・カタログ作成
└── .github/
    └── workflows/
        └── deploy-pages.yml
```

- **2列**：日本語例文、訳文（1列目→2列目）。一部の添付CSVは1列目が英語単語ですが、**列の順番は変更しません**。
- **3列**：中国語原語、拼音、日本語訳。
- **4列**：単語、日本語訳、例文、例文の日本語訳。
- **5列**：4列＋例文の強調箇所（太字・下線）。
- 1行目には**任意のカラム名**を入れてください。カラム名自体は照合しません。データは2行目から。
- UTF-8（BOMあり／なし）、標準のCSVダブルクォートに対応。CSV内でカンマや改行を使う場合はセルをダブルクォートで囲んでください。
- 言語はファイル名と実際の外国語テキストから自動判定します。曖昧なファイルは `韓国語`、`英語`、`HSK`などを**ファイル名に含める**と判定しやすくなります。3列は中国語として判定します。

## GitHubへ反映する

1. ZIPを**解凍**し、`index.html` がGitHubリポジトリ直下になるようにアップロード・上書きします。
2. **`app.js`、`styles.css`、`sw.js`、`index.html`、`scripts/build_site.py`** は必ず置き換えてください。
3. `VocabularySets/Flash`、`VocabularySets/Vocabulary` に同梱のCSVを置きます。GitHubに以前のCSVが残っている場合は、必要に応じて**古い不要なCSVを削除**してください。単にアップロードするだけでは旧ファイルが残り、重複表示されます。
4. `.github/workflows/deploy-pages.yml` は前回と同じなので、**既存のGitHub Actionsが動いていれば更新不要**です。GitHub Settings → Pages の Source は GitHub Actions のままにします。
5. コミット後、Actionsタブの `Deploy たんたんご PWA` が成功すると公開されます。`scripts/build_site.py` が27セットを検出・各言語へ割り振ります。
6. **PWAアイコンの削除・URL変更はしない**でください。更新後はオンライン状態でPWAを開き直してください。

## ⭐の引き継ぎと注意

- これまでと同じ`kotobadeck-local-sets`・`review-flags`（IndexedDB）を使用します。データベースのバージョンも変更していません。
- `第47回TOPIKⅡ_上級韓国語100単語(1).csv` は同じ100語のままファイル名だけ変更されたため、**旧名で保存した⭐を新名へ移す処理**を加えました。
- ほかのセットは、**ファイル名と単語／訳の組み合わせが一致**していれば⭐が引き継がれます。異なるファイル名へ変更したCSVの⭐は自動移行できない場合があります。
- ブラウザやiPhoneのサイトデータを消去すると保存情報が失われる場合があります。

## 手元で確認

```bash
python3 scripts/build_site.py
cd dist
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。GitHub Pagesでは`dist/`の中身がデプロイされます。
